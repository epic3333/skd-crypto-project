# skd-crypto-project

This is a project for Ethereum smart contract development using Hardhat.

## Getting Started

1.  Install dependencies:

    ```bash
    npm install
    ```

2.  Initialize a sample Hardhat project:

    ```bash
    npx hardhat
    ```

3.  Compile contracts:

    ```bash
    npx hardhat compile
    ```

4.  Run tests:

    ```bash
    npx hardhat test
    ```
